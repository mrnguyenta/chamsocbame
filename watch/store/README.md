# Ảnh cho trang Connect IQ Store

- `hero-1440x720.png`: Hero Image (1440×720, PNG, dưới 2 MB).
- `cover-500x500.png`: Cover Image (500×500, PNG, dưới 300 KB); bản thiết kế `cover.html`.
- `hero.html`: bản thiết kế. Render lại: nhúng font Be Vietnam Pro (Google Fonts) vào chỗ chú thích trong `<style>`,
  mở bằng Chromium khung 1440×720 rồi chụp màn hình.
- `screen-*.png`: Screen Images (454×454, PNG, dưới 150 KB): màn hình mã kết nối và màn hình nhịp tim,
  tiếng Việt (`_vi`) và tiếng Anh (`_en`). Vẽ lại theo đúng bố cục `watch/source/MainView.mc`; bản thiết kế `screens.html`
  (mở `screens.html#main_vi`, `#pair_vi`, `#main_en`, `#pair_en`).
